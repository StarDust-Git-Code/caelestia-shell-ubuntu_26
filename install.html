Caelestia Shell Setup

A stunning Wayland desktop experience for Ubuntu 26.04

1
Open Terminal

Launch your default Ubuntu terminal application. You can usually do this by pressing Ctrl + Alt + T on your keyboard.

2
Clone the Repository

Download the Caelestia Shell source code. It is critical to include the --recursive flag so all necessary submodules are downloaded.

git clone --recursive https://github.com/caelestia-dots/shell.git
3
Navigate to the Folder

Change your current directory into the newly downloaded repository folder.

cd shell
4
Run the Installer Script

Make the script executable and launch the installation process. The script will request your password to install system dependencies via apt.

Note: Do not run the script as root (do not use sudo before ./install-ubuntu.sh). The script will prompt for it automatically when needed.

chmod +x install-ubuntu.sh ./install-ubuntu.sh
5
Grab a Coffee

The installer will compile Hyprland, Quickshell, and the Caelestia ecosystem from source. Depending on your hardware and internet connection, this process will take anywhere from 30 to 60 minutes.

6
Log Out & Switch Sessions

Once the installation completes successfully:

  1. Log out of your current Ubuntu session.
  2. At the login screen, click your username.
  3. Look for a gear icon (usually bottom right) and click it.
  4. Select "Caelestia (Hyprland)" from the list.
  5. Enter your password and log in to experience your new desktop!
